## Description
- Python library with useful tools that makes easier the hard process of dates manipulation
## Tools
- datetime now: This method gives the current date and time.
- Strftime and Strptime: Converts between Datetime class to string and string
 to Datetime, in the format that you decide (string argument to choose the spaces)
 - Time delta: Works like a datetime result after a process, with a specific hour, week, minutes, ETC.
